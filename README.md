# ОдинКод

Мобильный каталог промокодов: посетитель получает трёхминутную бесплатную сессию и может раскрыть один выбранный код. Подписка за 10 ₽ каждые 30 дней открывает весь каталог.

## Готовые функции

- поиск и фильтрация большого каталога;
- серверный таймер бесплатной сессии;
- один бесплатный код на подписанный браузер;
- безлимит для подписчика;
- явное согласие на автопродление;
- отмена автопродления в один клик с сохранением доступа до конца периода;
- демонстрационная оплата без списания;
- каркас ЮKassa с redirect-платежом, сохранением способа оплаты и проверкой webhook через API;
- фоновое продление подписок по сохранённому `payment_method_id` с устойчивым ключом идемпотентности;
- загрузка активных купонов из Admitad и дополнительных разрешённых HTTPS JSON-лент;
- автоматическая синхронизация каталога без перезапуска сервера;
- дедупликация кодов и удаление истёкших предложений;
- название конкретного сервиса и источник на каждой карточке;
- коды не передаются браузеру до разрешённого раскрытия;
- `.env`, база состояния и исходники не раздаются веб-сервером.

## Запуск демонстрации

```text
npm test
npm start
```

Откройте `http://localhost:8010`. Жёлтая плашка честно сообщает, что встроенные коды демонстрационные и в магазинах не работают.

## Бесплатная публикация для проверки площадки

В репозитории есть `render.yaml`: Render может бесплатно запустить проект и выдать постоянный HTTPS-поддомен `*.onrender.com`. После подключения репозитория выберите Blueprint и план Free. Банковская карта для бесплатного развёртывания не требуется.

Бесплатный Render засыпает без трафика и использует временную файловую систему. Поэтому такой адрес подходит для демонстрации и проверки площадки Admitad, но реальные подписки нельзя включать до подключения постоянной базы данных. В `render.yaml` оплата и фоновые задания намеренно выключены.

## Настоящие промокоды

1. Зарегистрируйте площадку в Admitad.
2. Подключитесь к рекламным программам и получите разрешённые для площадки купоны.
3. Скопируйте `.env.example` в `.env`, добавьте `ADMITAD_ACCESS_TOKEN` и `ADMITAD_WEBSITE_ID`.
4. Запустите сервер. Он обновит каталог сразу и затем каждые `PROMO_SYNC_MINUTES` минут. Для ручного запуска используйте `npm run sync:promos`.

Синхронизация сохраняет только купоны со статусом `active`, непустым кодом и неистёкшей датой. После появления `data/promos.live.json` приложение автоматически перестаёт использовать демонстрационный каталог. Через `PARTNER_FEEDS_JSON` можно подключить несколько выданных вам партнёрами HTTPS-лент; не добавляйте коды, на публикацию которых у площадки нет разрешения.

## Настоящая подписка

1. Заключите договор с ЮKassa и включите автоплатежи.
2. Заполните `YOOKASSA_SHOP_ID`, `YOOKASSA_SECRET_KEY`, `BASE_URL` и длинный `SESSION_SECRET`.
3. Установите `PAYMENT_MODE=yookassa`.
4. В личном кабинете ЮKassa добавьте уведомление `payment.succeeded` на `https://ваш-домен/api/webhooks/yookassa`.
5. Сервер сам проверяет продления каждые `BILLING_INTERVAL_MINUTES` минут; `npm run bill` оставлен для ручной проверки или внешнего планировщика.

Первая оплата создаётся с `save_payment_method: true`. Webhook не считается доверенным сам по себе: сервер запрашивает платёж из API ЮKassa и только после статуса `succeeded` активирует доступ. Повторный webhook не продлевает период дважды. Если webhook задержался, сайт проверит незавершённый платёж после возврата пользователя из ЮKassa. Данные банковской карты проект не получает и не хранит.

Повторное списание использует сохранённый `payment_method_id`, формирует данные чека и устойчивый ключ идемпотентности на расчётный период. До реального запуска нужно добавить уведомление перед списанием, политику обработки данных, оферту, страницу поддержки и удаление аккаунта. Эти части требуют реквизитов бизнеса и боевых настроек ЮKassa.

## Важная модель продукта

Плата взимается за доступ к каталогу, а не за шанс выиграть. Пользователь сам выбирает предложение, проигрышных вариантов нет. Таймер ограничивает бесплатную сессию, но не изображает ложный срок действия скидки.
